照平常的方式改選字、Shift + ← / → 選範圍按 Enter 加詞、Enter 送出取代原文；Esc 放棄時放回原文。

## M8 T0：內建語言模型重新排序（規劃，2026-11-15）
做法：包住 chewing 的轉換引擎（`ConversionEngine` 是公開介面），chewing 產生前幾名候選句，
T0 用自己訓練的字 n-gram 語言模型重新打分、選最通順的當首選。純查表，每次按鍵 < 1 ms，不需要 GPU 或 LM Studio。
語料：中文維基百科（CC BY-SA，轉台灣正體）+ 本機 LLM 針對易錯同音字生成的句子。模型隨安裝程式發布，標示來源。

- [ ] 語料：下載維基 dump（不進 repo，放 `.corpus/`），抽出內文、OpenCC 轉台灣正體、切句，保留一份做評測不參與訓練
- [x] `zct-train`：字 3～4-gram 計數 + 平滑（Kneser-Ney 或 stupid backoff）+ 修剪，輸出幾 MB 的二進位模型
- [x] zct-core：模型載入（mmap 或一次讀入）、句子打分；包住 ChewingEngine 的 ConversionEngine 重新排序 n-best
- [ ] 評測：擴大評測語料（維基保留集 + 現有 111 句 + 口語句子）；首選正確率要高於現在、任何一類都不能變差才啟用
- [ ] LLM 補強：用 qwen3.5-4b 針對在/再、交/教、的/得/地… 生成口語句子，加進訓練語料
- [ ] 設定開關（預設開，評測通過後）、文件、授權標示（CC BY-SA 來源）

### T0 評測紀錄
- 維基第 1 份（1.13 億字）4-gram，114 MB。自寫 111 句 / 維基保留 1,000 句：不用 T0 99.42% / 95.39%；權重 0.3：99.06% / 96.99%；0.6：98.92% / 97.25%
- 異體字合併（臺＝台、賬＝帳…）前，自寫語料會被改成臺、宣佈、賬單 → 合併後改善

- 模型格式 v2：32 位元指紋 + 量化分數（5 bytes / 筆）

## 共用主機層：平台只負責 UI 與 IO（規劃 2026-11-20，待使用者確認）

現況：Windows 的 `zct-service/conn.rs` 與 macOS 的 `zct-ffi` + Swift 各自實作同一套「主機」邏輯，已經出現分歧
